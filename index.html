Sistem sederhana untuk melihat slot parkir motor yang masih kosong

Petunjuk: Klik slot untuk mengubah statusnya. Slot kosong menjadi terisi, dan slot terisi dapat diklik lagi untuk mengosongkannya. Data parkir tersimpan otomatis untuk pemakaian setiap hari. Tombol Restart / Reset hanya dapat digunakan oleh penjaga parkir atau pemilik.

🌐 Mode Online: Setelah Firebase dikonfigurasi, status slot disimpan di database online. Artinya HP siswa dan HP penjaga dapat melihat status parkir yang sama secara real-time.
Jika tulisan masih “Database belum terhubung”, isi konfigurasi Firebase pada kode.
💡 Solusi: Siswa dapat melihat slot kosong terlebih dahulu sehingga tidak perlu berputar-putar mencari tempat parkir.

📘 Cara Mengaktifkan Versi Online

  1. Buat project baru di Firebase.
  2. Aktifkan Realtime Database.
  3. Tambahkan aplikasi Web dan salin firebaseConfig.
  4. Ganti nilai ISI_... pada bagian konfigurasi Firebase di file ini.
  5. Upload file ke hosting (misalnya GitHub Pages, Netlify, atau Firebase Hosting).
  6. Bagikan link website atau buat QR Code untuk siswa.

Catatan: PIN Restart tetap digunakan di sisi halaman. Untuk penggunaan sekolah yang serius, akses penjaga sebaiknya ditingkatkan menjadi login Firebase agar PIN tidak terlihat di source code.
